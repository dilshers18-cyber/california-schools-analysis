## Upwork project

**Title:** California Schools Data Analysis | SQL, Python & Data Visualization

**Description:** I analyzed a historical California schools database using SQLite, pandas and Matplotlib. The project combines three tables, validates school identifiers, handles missing values, and answers five questions about school SAT results, FRPM eligibility and opening trends. Deliverables include reusable SQL queries, a portable Python workflow, five charts, CSV exports, and a documented findings report. Independent pandas checks validate the SQL results. Sample sizes, reporting-period uncertainty, and the distinction between correlation and causation are explicitly documented.

**Skills:** SQL; Python; pandas; data cleaning; data visualization.

**Suggested cover:** `outputs/05_frpm_sat.png`.

**Interview explanation:** “I started with a notebook that relied on local SQL files. I made the workflow reproducible, corrected the SQL schema and percentage calculations, added a genuine yearly trend, and validated joins and aggregates. I also distinguished school-weighted from test-taker-weighted county averages and documented limitations rather than overstating the findings.”
